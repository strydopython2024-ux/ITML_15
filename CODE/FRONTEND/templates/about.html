ABOUT THE PROJECT

Smart Farming Soil Prediction

A machine learning based system designed to analyze soil and environmental conditions and predict the most likely soil type.

01

Enter Conditions

Provide N, P, K, soil pH, temperature, humidity, season and water source.

02

Machine Learning

The trained soil classification model processes the supplied conditions.

03

View Result

Receive the predicted soil type together with the model confidence.

System Overview

The application combines a Flask web application with a trained machine learning soil prediction model. User authentication, prediction history and model inference are handled through the backend, while the interface is built using responsive TailwindCSS components.
